# Code With ABM 🌐

Welcome to the official repository for **Code With ABM** — a creative web development and design company specializing in **HTML, CSS, branding, and modern front‑end solutions**.

---

## 🚀 About Us
At Code With ABM, we believe coding is more than syntax — it’s about **learning, building, and sharing**.  
We focus on:
- Professional **web development** (HTML, CSS, JavaScript basics, responsive design)
- **Branding & creative design** for businesses
- Building **portfolio websites** and company pages
- Simplifying tech for learners and professionals

---

## 🛠 Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (basic interactivity)
- **Design Tools:** Canva, Figma, Photoshop
- **Deployment:** Netlify (global CDN hosting)
- **Version Control:** Git & GitHub

## 📂 Project Structure
- `index.html` → Main homepage  
- `thank-you.html` → Redirect page after form submissions  
- `assets/` → Images, icons, and style resources  
- `css/` → Stylesheets for layout and branding
